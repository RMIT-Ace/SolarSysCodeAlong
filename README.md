# SolarSysCodeAlong

![](docs/res/solarsys-codealong.gif)

Immersive Programming Code-Along presentation using SolarSys as example.

## Immersive Experience (MX)
- Augmented Reality (AR)

    Enhanced real world by layering digital content on top.

- Virtual Reality (VR)

    Fully immersive, computer-generated environment that replace real-world perception.

## Immersive Programming with Apple Technologies

- macOS 26
- iOS 26
- Xcode 26
- RealityKit Framework
- SwiftUI Framework
- Swift programming language
